React Article Sort Application

A React.js application that enables users to add articles, store them in Local Storage, and sort them based on upvotes or publication date. The project demonstrates React state management, form validation, Local Storage operations, and sorting algorithms.

Features
Add new articles
Form validation
Store article data in Local Storage
Sort articles by upvotes
High to Low
Low to High
Sort articles by date
Recent First
Oldest First
Delete articles
Clear Local Storage
Dynamic table rendering

Technologies Used
React.js
JavaScript (ES6)
HTML5
CSS3
Local Storage API
